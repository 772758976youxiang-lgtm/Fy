聊天与工具
支持流式答案、折叠思考、none/low/high/max 强度、停止、重试、会话重命名/删除/导出。
思考过程默认折叠，工具执行状态和网页来源统一收纳其中；回答正文保留模型答案与文内引用。
模型输出的独立行 ⟨幕后⟩ / ⟨/幕后⟩ 区块会收进过程区，标记为「幕后附注 · 模型生成」，不算真实工具调用；代码示例中的标记保持原样。
复制回答和导出 Markdown 正文不包含幕后附注；完整 JSON 备份和模型上下文仍保留原始内容。折叠不是加密或访问权限控制。
网页搜索开关启用 web_search；工具开关启用 web_fetch、get_current_time 和已启用的自定义工具，最多五轮工具后完成回答。
web_fetch 在后端读取公共网页；限制跳转、大小、时间，阻止本机及内网请求。
自定义工具只在连接本地后端时可用；模型只能填写你声明的运行参数，不能更改固定配置。
纯浏览器直连提供时间和原生搜索工具；跨域限制时请连接后端。
Enter 发送，Shift+Enter 换行，Ctrl+K 新对话。

添加自定义工具
设置 → 工具调用 → 添加工具。可选择 LLM、评判模型、图片生成、视频生成、HTTP、MCP、本地命令。
列表中点击编辑按钮旁的复制图标，会立即保存一个默认禁用的独立副本并打开编辑页；名称自动避重，完整保留配置、运行参数和密钥保存方式。
独立 API Key 仅在后端复制，不返回浏览器。取消编辑不会删除已创建的副本；修改或删除副本不影响原工具。复制不会执行工具或调用模型。
填写显示名称、唯一工具名称（英文/数字/下划线）、用途说明；用途说明用于主模型按需选择工具。
固定配置包含完整接口 URL、模型、none/low/high/max 思考强度、API Key、系统提示词、鉴权与超时。
LLM/评判模型使用 POST messages 请求时，只填域名或以 /v1 结尾的基础地址，会自动补全 /chat/completions；其他自定义路径及工具类型按完整 URL 请求。
普通 LLM 工具不自带联网和实时数据能力。查询实时天气等信息需开启主对话网页搜索，或配置提供真实数据的专用接口。
高级配置中可编辑请求体、请求头、输出类型、结果字段路径；模板是起点，须按实际服务文档调整。
请求体里的 {{args.prompt}} 引用运行参数，{{config.model}}、{{config.effort}}、{{config.systemPrompt}} 引用固定配置。
整个字段为占位符时保留 JSON 类型；字符串中嵌入占位符时只支持标量。密钥通过鉴权配置注入，不支持在模板中读取。
运行参数支持 string/number/integer/boolean/object/array、必填、JSON 默认值、JSON 可选值与数组元素类型。
结果字段路径使用点号，例如 choices.0.message.content 或 data.0.url。图片/视频返回 HTTP(S) 链接，暂不接收内联 Base64 媒体。
异步任务可开启轮询：设置同源轮询地址（例如 https://example.com/jobs/{{result.id}}）、状态路径、成功/失败状态、次数及间隔。
「试运行」会真实调用接口，可能产生服务商费用；保存配置不会调用模型。工具列表支持编辑、启停、删除。
MCP 使用 Streamable HTTP，支持发现工具并导入基础参数；不包含 stdio、旧版 SSE 或 OAuth 登录流程。
CLI 使用固定可执行程序和参数数组，不通过 shell 拼接命令；不支持 cmd/bat 或 shell 启动器。参数可使用 {{args.prompt}}。
CLI 每次执行必须确认；其他工具可勾选「执行前确认」。等待确认时会展开过程区，显示参数和允许/拒绝按钮。
停止或确认超时后不能继续批准旧请求。CLI 取消终止直接启动的进程，不能保证终止程序自行派生的后台进程。
仅添加可信服务和本机程序。自定义工具可以访问你配置的本地接口，也可能产生文件、网络或计费副作用。

AI 协助创作工具
设置 → 工具调用 → 右上角「AI 协助创作」。输入需求或粘贴接口文档、请求/响应示例，点击「生成配置」。
使用已保存的主模型、思考强度和主模型 Key，生成名称、类型、固定配置、运行参数、请求模板、结果路径及轮询配置。
生成会调用模型并可能计费，不会搜索网页、读取聊天记录、自动执行工具或保存工具；仅粘贴链接不会自动读取网页。
先查看配置草稿与待补充项，再点击「应用到表单」。检查接口与参数、补充缺失值后，另行保存工具。
已有独立 API Key 保留在本地，现有请求头和环境变量值不会发给生成模型；可识别的凭据会脱敏，但请勿在需求或文档中粘贴秘密。
应用保留已有密钥与执行确认设置；CLI 始终需要执行前确认。请核对 AI 生成内容后再试运行。
支持停止、重新生成、放弃草稿；预览后若修改过表单，需要重新生成，避免覆盖手动修改。
关闭工具编辑或设置会丢弃创作输入与未应用草稿；这些内容不会写入会话或本地存储。

数据
设置/会话保存至自动生成的 data/。Key 默认只存服务内存，重启需重新输入。
记住密钥后写入 data/credentials.json（未加密），不要共享该文件或含 data/ 的后端文件夹。
自定义工具配置保存至 data/tools.json；独立 API Key 默认仅存内存，勾选记住后保存至 data/tool-credentials.json（未加密）。
请求头、环境变量和请求体属于普通固定配置，会保存到 tools.json；敏感凭据应使用独立 API Key 字段。
读取设置和导出会话不包含配置中的 Key；聊天中自行输入的任何内容会随会话导出。
连接码保留在当前标签页会话。直连记录与后端记录分别保存，断开可回到直连记录。
关闭服务后备份 data/，恢复时放回同一位置。移除密钥同时清除服务内存及落盘凭据。

验证及源码
按需搜索回归测试：在后端目录执行 node --test tests/search-on-demand.test.js。
完整回归测试：安装 Playwright 和 Chrome 后执行 node --test tests/*.test.js；可用 LUMA_TEST_BROWSER 指定浏览器通道。
自动测试覆盖协议、流式解析、工具循环、取消、认证、存储、抓取限制；浏览器以模拟上游联调。
自定义 HTTP/MCP/CLI 自动测试使用本地模拟服务和无副作用的测试程序；真实服务可通过「试运行」单独验证。
网页提取为基本文本/HTML 提取，不运行网页脚本；压缩/二进制页面会拒绝。
原创 HTML/CSS/JavaScript 界面，无 CDN；后端使用 Node.js 内置模块，无需 npm install。
